# North American Sports Map

An interactive web map showing all MLB, NBA, NHL, and NFL teams across North America with live team records pulled from real APIs.

## How to Run

1. Unzip the `sports-map.zip` file into a folder
2. Open the folder and double-click `index.html`
3. It will open in your web browser — no installation needed

## Features

- Interactive map of North America with pins for every team
- Live MLB standings and win/loss records fetched from the MLB Stats API
- NBA, NHL, and NFL team locations with 2025–26 standings
- Click any team pin to see team info and current record
- Filter by sport using the buttons on the page

## Files

- `index.html` — the main page
- `style.css` — styling and layout
- `script.js` — map logic and API calls

## Requirements

Just a modern web browser (Chrome, Firefox, Edge, Safari). No server or software installation required.
